# 桌宠素材来源与许可

内置三只桌宠的头像、原声素材来自下面三个开源项目，仅用于本机个人使用，不商用。

- 孙宇晨（太对了）：[Ganzhe2028/SunPet](https://github.com/Ganzhe2028/SunPet)（MIT）
- 峰哥（好事）：[Ganzhe2028/FengGe-Desktop-Pet](https://github.com/Ganzhe2028/FengGe-Desktop-Pet)（MIT）
- 邵艾伦（薄肌）：[Ganzhe2028/ShaolanPet](https://github.com/Ganzhe2028/ShaolanPet)（MIT）
- Windows 整合与接话逻辑参考：[wanzhijie1/Alan-Desktop-Pets-Windows](https://github.com/wanzhijie1/Alan-Desktop-Pets-Windows)

代码部分沿用 MIT 许可。人物头像和音频录音的版权属于原权利人，不在 MIT 许可范围内。若权利人提出异议，请删除对应素材。

|---|---|---|
